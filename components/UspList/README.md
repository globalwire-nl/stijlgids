# UspList

De beloftes van DectDirect als lijst met icoon: groot op violet op de homepage, klein in de kolom van de productpagina.

## Gebruik
- Op violet (`color-violet-900`, `radius-md`): kop "Op ons kun je rekenen.", regels 20px vanaf lg, iconen 32px in `color-yellow-500` (5,8:1).
- In de hero: vinkjes (`check`) in `color-yellow-500` met vier regels.
- Op de productpagina: kop `heading-small`, iconen in `color-brand`, de installatieservice als link in `color-sky-500`.
- Vaste beloftes en hun woorden: **gratis** verzending binnen de Benelux (EU tegen betaling), **Installatieservice** kant-en-klaar of op locatie, kopen **op rekening** voor de zakelijke markt, Professioneel **advies**, altijd minimaal **2 jaar garantie**, Klantbeoordeling **9.2/10** (in de hero "9,2"). Het belangrijkste woord is bold.
