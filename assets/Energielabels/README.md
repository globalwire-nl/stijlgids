# Energielabels

De EU-energieklassen A tot G als pijltje met de schaal. Altijd direct bij de prijs (NVWA-eis), op tegels en op de productpagina, met ernaast de link "Productinformatieblad" (13px, `color-neutral-900`). Een klik opent het volledige label in een dialoog. Kleuren zijn die van de EU-norm: niet aanpassen.
