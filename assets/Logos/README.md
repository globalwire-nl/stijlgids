# Logos

- `logo.svg`: volledig logo (beeldmerk + woordmerk) voor lichte grond; header vanaf lg, 40px hoog. Kleuren in het bestand: verloop #5d2b95 → #1196c9 in het merk, "dect" #54379b, "direct" #3591c6, punt #f2bc17.
- `logo-white.svg`: hetzelfde voor donkere grond ("dect" wit). Header in donker, en op `color-violet-900`.
- `logo-without-mark.svg` / `logo-without-mark-white.svg`: alleen het woordmerk, header onder lg (32px hoog).
- `mark.svg`: het losse beeldmerk (de D), app-icoon van de winkel.
- `apple-icon.png`, `favicon.png`: pictogrammen voor browser en telefoon.

Meerkleurig: niet hertinten, niet op een verloop of foto zetten, en altijd de witte variant op donker.
