# CompactProductCard

Een product als één smalle rij: foto van 80px links, naam en prijs rechts, met de compacte gele knop.

## Gebruik
- Voor smalle plekken: "Vaak samen gekocht" op de productpagina en de kolom naast een adviesartikel.
- Zelfde ring en hover als ProductCard (1px `color-neutral-200`, hover 2px `color-brand`); fotovlak wit met rand rechts.
- Naam `text-sm` bold `color-neutral-700`, 2 regels; prijs 16px bold.
- Zonder voorraad: "Niet op voorraad" in `text-xs color-neutral-400` op de plek van de knop (2,6:1, bron).

## Wat de gebruiker levert
Hetzelfde product-object als ProductCard (naam, slug, sku, stock, prijs, image_url).
