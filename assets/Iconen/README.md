# Iconen

- `tabler/*.svg`: de UI-iconen van de winkel, Tabler Icons v3.46.0 (MIT), onder de namen die `components/Icon.js` gebruikt. Omlijnd: lijndikte 2, ronde uiteinden, raster 24. Gevuld: `starFilled`. In de winkel tekenen ze in `currentColor`; deze bestanden hebben één inkt, #262626 (`color-neutral-800`), omdat een `<img>` geen kleur erft. Wie ze inline als SVG gebruikt, zet `stroke="currentColor"`.
- `check.svg`, `check-small.svg`: gele vinkjes (#f6c406, `logo-yellow`).
- `cross.svg`: grijs kruisje (#969696).
- `recycle.svg`: wit recycle-teken voor Tweedekans, op een donkere grond.
- `icon-avondverzending.svg`: busje in violet en geel naast de levertijd op de productpagina (31×17).
- `footer-instagram.svg`, `footer-linkedin.svg`: sociale iconen in de footer, violet met geel (20px).
