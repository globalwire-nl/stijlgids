# Badge

Violette labels: de Bestseller-badge, het productlabel uit de backoffice en de teller op het winkelwagen-icoon.

## Gebruik
- `dd-badge`: `radius-full`, `color-violet-900` met wit, `badge`-tekststijl, `shadow-sm`. Bestseller krijgt het `starFilled`-icoon (12px). Linksboven op de productfoto, onder elkaar.
- `dd-label`: het label op de productpagina (zoals in het Lightspeed-thema): `radius-md`, 14px, met `info`-icoon als er uitleg is. De uitleg is een tooltip (`color-neutral-100`, `shadow-md`) die ook op tik/focus opent; focus-ring 2px `color-yellow-400`.
- `dd-cart-count`: 18px rond, 11px bold, rechtsonder op het icoon; speelt `animate-fadeIn` bij elke toevoeging.
- `color-violet-900` is in beide thema's gelijk; wit erop 11:1.
