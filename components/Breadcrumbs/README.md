# Breadcrumbs

Het kruimelpad boven categorie-, product- en contentpagina's.

## Gebruik
- `small`-tekst in `color-neutral-500` (4,7:1), scheiding "›", hover `color-sky-500`. De laatste stap is geen link en wordt afgekapt als hij te lang is.
- Begint altijd met Home. Op de productpagina volgt het de categorie van het product.
