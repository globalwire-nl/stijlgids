# Pagination

Paginering onder een productraster (24 producten per pagina).

## Gebruik
- Vakjes van minimaal 40×40px, rand `color-neutral-200`, `radius-md`, bold. Links in `color-sky-500` met hover-rand `color-sky-500`; de huidige pagina in tekstkleur en niet klikbaar. Pijlen voor vorige/volgende, sprongen met "…".

## Let op
- `color-sky-500` op wit is 2,7:1 (bron).
