# Categorie-iconen

Eén icoon per hoofdcategorie: een violette schijf (#5d378d, `icon-violet`) met een wit symbool, 50×50. `cat-xelion.svg` (Cloud telefonie) heeft zijn eigen tekening.

Gebruik in het hoofdmenu (50px vanaf lg, 40px eronder) en in de categorielinks op de homepage (32px). Niet hertinten.
